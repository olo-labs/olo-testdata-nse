# Documentation image assets

## OLO DB Viewer snapshot

`olo-db-viewer-snapshot.png` is the stable screenshot used by the root README, quick-start guide, viewer README, and AI discovery index.

To publish a newer interface capture:

1. Capture the OLO DB Viewer with representative OHLC, volume, and delivery data visible.
2. Remove or avoid private paths, credentials, account information, and other sensitive content.
3. Replace `olo-db-viewer-snapshot.png` with the new PNG.
4. Keep the filename unchanged so every existing Markdown reference continues to work.
5. Preview the root README and `docs/QUICKSTART.md` to confirm the image remains readable.

The current image is intentionally a replaceable documentation asset, not an application runtime dependency.
